---------------------------------------------------
MATLAB GPU Acceleration for Wi-Fi 7 EHT Receiver
---------------------------------------------------

This project implements a GPU accelerated Wi-Fi 7 EHT receiver using MATLAB

The goal is to compare a CPU-based and GPU based receiver execution for large packet workloads.

Features:

1. End to end EHT receiver provessing
2. MATLAB CPU implementation
3. CUDA MEX GPU acceleration
4. Batched GPU packet processing
5. Parallel CPU benchmarking
6. 4096-QAM EHT processing
7. LDPC decoding
8. CPU vs GPU comparison
9. Configurable packet-count sweeps

Requirements

1. MATLAB
2. WLAN Toolbox
3. Parallel Computing Toolbox
4. NVIDIA CUDA-capable GPU
5. Compatible NVIDIA GPU deiver
